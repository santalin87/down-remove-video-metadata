What hidden data do downloaded videos carry?

Videos downloaded from platforms are rarely "clean". They typically carry several layers of identifying information: platform SEI codes — small data packets embedded directly in the video stream that record which platform the file came from; container metadata — title, author, creation tool and encoder strings stored in the file header; and chapter markers or custom data boxes the platform injected. Re-uploading such a file elsewhere lets the new platform read exactly where it came from.

  2. Choose an editor preset and clean. One click strips platform SEI codes (H.264 and HEVC), wipes container metadata and chapters, and re-stamps the file as an export from Premiere Pro, DaVinci Resolve, or CapCut — including the encoder identification string.
  3. Download. The file is stream-copied, so processing takes seconds and quality is 100% identical — not a single pixel is re-encoded.

Why no re-encoding matters

Most "cleaning" advice tells you to re-encode the video, which degrades quality and takes minutes. This tool only rewrites the container: the video and audio streams are copied bit-for-bit (stream copy), while the metadata layer is rebuilt from scratch. The result is mathematically identical video with a clean identity — done in seconds, even for large files.

Private by design: nothing is uploaded

This tool runs FFmpeg, the industry-standard video engine, compiled to WebAssembly and executed entirely inside your browser tab. Your video never travels over the network. The metadata surgery (including the encoder-string patch) also happens locally in your browser's memory.

An honest note on "originality"

Cleaning metadata defeats metadata-level and file-hash identification: the file hash changes, platform codes are gone, and the encoder string reads as your chosen editor. It does not defeat content-based fingerprinting — if a platform recognizes the actual pictures and sounds, no metadata trick will hide that. Use this tool for what it is: a fast, lossless metadata cleaner, not an invisibility cloak.
